# Hugo学习笔记

### 内容介绍

Hugo是由Go语言实现的静态网站生成器。简单、易用、高效、易扩展、快速部署。

Hugo以速度快著称，号称是世界上最快的网站生成框架。

**The world’s fastest framework for building websites**

![](content/docs/introduction/images/hugo-icon-big.png)
